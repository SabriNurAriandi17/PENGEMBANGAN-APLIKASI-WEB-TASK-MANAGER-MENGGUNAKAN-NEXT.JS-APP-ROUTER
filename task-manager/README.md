# Task Manager (Next.js App Router)

Aplikasi Task Manager sederhana untuk tugas mata kuliah Pengembangan Web.

## Fitur
- CRUD tugas (tambah, lihat detail, edit, hapus)
- Filter berdasarkan status (Belum / Proses / Selesai)
- Tandai tugas selesai langsung dari daftar (checkbox)
- Halaman daftar tugas menggunakan Server-Side Rendering (SSR)

## Menjalankan proyek

```bash
npm install
npm run dev
```

Buka http://localhost:3000

Lihat **DOCUMENTATION.md** untuk penjelasan struktur folder, alur data,
tantangan umum & solusinya, serta langkah kerja untuk laporan.
